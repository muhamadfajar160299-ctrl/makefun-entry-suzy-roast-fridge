A single-line roast of my fridge, written by a small Python program.

## How it works

`main.py` (Python 3, standard library only) reads the one-line roast from
`entry.txt` and writes it to `MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).

## Run

```sh
python3 main.py
```

## Entry

The roast itself lives in `entry.txt`: one line, at most 200 characters.
